# ImageLab

Editor de imagens no navegador, desenvolvido com HTML, CSS e JavaScript.

## Funcionalidades

- Carregamento de imagens.
- Filtros visuais e ajustes manuais.
- Corte, rotação e espelhamento.
- Redimensionamento, compressão e conversão.
- Exportação e download dos resultados.
- Desfazer a última edição aplicada.

## Executar localmente

Com Python 3 instalado, execute:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Depois, abra http://127.0.0.1:8000 no navegador.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Python 3 para servir os arquivos localmente
